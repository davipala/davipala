### [Virtual MRI Scanner](https://github.com/davipala299/COSC4372-Virtual-MRI-Scanner)

A COSC 4372 project that simulates MRI acquisition and image reconstruction using Cartesian and radial trajectories. Its interactive GUI works with two image phantoms and includes image-difference analysis tools.

A Django fuel-quote application with user signup, customer profile management, fuel price estimates, quote submission, and quote history. Pricing accounts for customer location, order history, gallons requested, and market conditions.
