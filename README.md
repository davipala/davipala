## Featured repositories

### [CV-DP-Sandbox](https://github.com/davipala/CV-DP-Sandbox)
An active sandbox for prototyping and testing ideas in computer vision and applied ML.  
This repository reflects my iterative development style: rapid experimentation, validation, and refinement of technical approaches before productionizing them.

### [cv_model_training](https://github.com/davipala/cv_model_training)
A project centered on computer vision model training workflows and supporting assets.  
It includes the foundations of model development pipelines—data preparation, training structure, and experimentation practices used to improve model performance and reproducibility.

### [Virtual MRI Scanner](https://github.com/davipala299/COSC4372-Virtual-MRI-Scanner)
A COSC 4372 project that simulates MRI acquisition and image reconstruction using Cartesian and radial trajectories.  
Features include an interactive GUI, support for multiple image phantoms, and image-difference analysis tools to evaluate reconstruction quality.

### [Fuel App](https://github.com/martinwiiin/COSC-4353)
A Django-based fuel quote application developed as part of a software engineering course project.  
Core functionality includes user registration/authentication, customer profile management, quote generation, and quote history tracking, with pricing logic based on customer and market-related factors.
